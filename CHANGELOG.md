Все заметные изменения проекта NoteSearch документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru-RU/1.1.0/), а версии используют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-05

Первый публичный релиз нативного macOS-приложения NoteSearch.

### Добавлено

- Полнотекстовый поиск по выбранному пользователем каталогу.
- Поддержка macOS на Apple Silicon, включая MacBook Air M1.
- Индексация Markdown, TXT, JSON, YAML, Python, JavaScript/TypeScript, HTML и CSS-файлов.
- Поиск без учёта регистра с поддержкой русского, английского и Unicode-текста.
- Поиск нескольких слов через логический `AND`.
- Точный фразовый поиск в кавычках.
- Debounce поиска при вводе.
- Список результатов с именем файла, относительным путём и количеством совпадений.
- Контекстные фрагменты вокруг совпадений: до 180 символов до и до 300 после совпадения.
- Подсветка совпадений и навигация по нескольким фрагментам.
- Открытие найденного файла через стандартное приложение macOS.
- Открытие файла в Finder.
- SQLite/FTS5-хранилище индекса в `~/Library/Application Support/NoteSearch/`.
- Инкрементальное обновление индекса при создании, изменении и удалении файлов.
- Наблюдение за каталогом через FSEvents.
- Настройка индексируемого каталога, поддерживаемых расширений и исключений.
- Сохранение пользовательских настроек.
- Глобальное сочетание клавиш `⌘⌥Space` для открытия окна поиска.
- Клавиатурная навигация по результатам и открытие файла через `Enter`.
- Логирование событий приложения через `AppLog`.
- Отдельный режим запуска при входе в систему через `SMAppService`.
- Release-скрипт `scripts/release.sh` для сборки arm64, ad-hoc-подписи, ZIP, DMG и SHA-256-сумм.
- Первичный набор unit-тестов для парсинга запросов, нормализации текста, поиска, сниппетов, индексации, обновлений и наблюдателя файлов.

### Подтверждено

- `swift test`: 86 тестов, 0 ошибок.
- Release-артефакты для версии `1.0.0` созданы:
  - `NoteSearch-1.0.0-arm64.zip`;
  - `NoteSearch-1.0.0-arm64.dmg`;
  - `SHA256SUMS.txt`.
- Контрольные суммы ZIP и DMG проверены успешно.
- Bundle ID: `ru.vincento.NoteSearch`.
- Архитектура релизной сборки: `arm64`.

### Ограничения релиза

- Поддерживается Apple Silicon; универсальная сборка Intel/x86_64 не заявлена.
- Релиз подписан ad-hoc, без Developer ID и нотарификации Apple.
- При первом запуске скачанного приложения macOS может потребовать разрешение через System Settings → Privacy & Security → Open Anyway.
- PDF, DOCX, OCR, поиск по изображениям, семантический поиск, синхронизация и поиск по всему Mac не входят в эту версию.
